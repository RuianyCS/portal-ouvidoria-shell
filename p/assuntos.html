Assuntos e Diagnósticos - IXC

COMO FUNCIONA A CLASSIFICAÇÃO NO IXC

A classificação de uma insatisfação tem 3 níveis encadeados, todos registrados no atendimento dentro do IXC:

1. ASSUNTO — a categoria-mãe da insatisfação (IDs oficiais 1056 a 1080). É o primeiro campo escolhido no registro do atendimento.

2. MOTIVO — o detalhamento do que aconteceu dentro do assunto (ex.: dentro de "Atendimento - Espera", o motivo "Espera no telefone").

3. DIAGNÓSTICO — o registro técnico do que de fato ocorreu/falhou, com ID próprio (33 diagnósticos oficiais + 2 pendentes de cadastro).

Fluxo correto: escolher o Assunto → selecionar o Motivo correspondente → registrar o Diagnóstico. Assunto sem motivo não fecha a insatisfação; diagnóstico sem assunto órfão deve ser evitado.

ORIGEM NO IXC

  • O ASSUNTO nasce no cadastro de assuntos do módulo de atendimento do IXC (menu de registro/suporte). Cada assunto tem ID numérico oficial (1056-1080) — usar sempre o ID para métricas.
  • O MOTIVO é cadastrado dentro de cada assunto, como subitens.
  • O DIAGNÓSTICO é registrado no campo de diagnóstico do atendimento, com IDs próprios da tabela oficial (aba DIAGNOSTICO da planilha oficial).
  • "Como aparece no IXC": o assunto aparece no seletor do atendimento; o motivo na lista dependente; o diagnóstico no campo técnico. Nos relatórios do IXC, o agrupamento por assunto é o nível 1 dos indicadores da Ouvidoria.
