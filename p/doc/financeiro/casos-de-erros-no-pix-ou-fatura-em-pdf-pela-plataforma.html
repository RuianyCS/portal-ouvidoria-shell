OBSERVAÇÃO: CASO ALGUM DESSES DADOS ESTEJA COM DADOS INCORRETOS OU NÃO PREENCHIDOS, VAI SER NECESSÁRIO PREENCHER O CAMPO SALVAR E VOLTAR NA PLATAFORMA DA BEMOBI E VALIDAR SE O PIX OU A FATURA VAI GERAR. COM ISSO NÃO É PARA CANCELAR A FATURA, PRIMEIRO ATUALIZA OS DADOS DO CLIENTE E DEPOIS ENTRA NA PLATAFORMA É VÁLIDA.

EX:

1º- Erro pois o cliente não tem uma data de nascimento válida

COM ISSO OS DADOS DO CADASTRO DO CLIENTE NÃO ESTIVEREM CORRETOS NEM O PORTAL DO CLIENTES ELE VAI CONSEGUIR ENTRAR.

NESSE CASO AQUI O IXC INSERIU A DATA DE FORMA INVÁLIDA E COM ISSO QUANDO A BEMOBI VAI TRANSFERIR OS DADOS PARA O BANCO ELE, ENCONTRA ESSE ERRO QUE NÃO PERMITE GERAR A FATURA E NEM O PIX.

IMPORTANTE LEMBRAR QUE ESSE É O CASO DO CLIENTE QUE JÁ TEM A FATURA GERADA, O CLIENTE QUE NÃO TIVER A FATURA GERADA, VAI PRECISAR GERAR NA CARTEIRA 24(SICOOB ARROBA REAL).
