COMO IDENTIFICAR CLIENTE NEGATIVADO SISTEMA/ SPC

1º- CONTRATOS>STATUS DO CONTRATO>STATUS DE ACESSO:

STATUS CONTRATO: NEGATIVADO

STATUS ACESSO: BLOQUEADO

Depois: NEGATIVAÇÃO DE CRÉDITO: para identificar se o cliente está inadimplente no SPC OU não.

QUANDO ELE ESTÁ NEGATIVADO NO SPC:

Se estiver com o status de ATIVO é por que ele está negativado no spc serasa e com isso, não conseguimos fazer a renegociação desse cliente ele vai precisar pagar o valor total de multa que estiver gerado no sistema:

CARTEIRA 12- MULTA DE QUEBRA DE CONTRATO

CARTEIRA 17- MULTA DE COMODATO

CARTEIRA 29- MULTA DE QUEBRA DE CONTRATO

CARTEIRA 28- MULTA DE COMODATO

Nesse caso o cliente precisa pagar o valor total de 867,90 para voltar a utilizar.

Caso ele não queira utilizar, ele precisa devolver os equipamentos para que o nome saia do spc.

QUANDO O CLIENTE ESTÁ NEGATIVADO APENAS NO SISTEMA

1º- CONTRATOS>STATUS DO CONTRATO>STATUS DE ACESSO:

STATUS CONTRATO: NEGATIVADO

STATUS ACESSO: BLOQUEADO

2º- PASSO:

NEGATIVAÇÃO DE CRÉDITO:

QUANDO O STATUS ESTIVER VAZIO NÃO ESTÁ INCLUSO NO SPC E COM ISSO CONSEGUIMOS FAZER A RENEGOCIAÇÃO PARA ELE, LEMBRANDO DE SEMPRE VERIFICAR SE ELE JÁ RENEGOCIOU.
