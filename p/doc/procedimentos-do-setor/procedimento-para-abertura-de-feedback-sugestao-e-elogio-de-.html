Procedimento para abertura de feedback, sugestão e elogio de clientes

O objetivo é garantir que todas as informações sejam registradas corretamente no sistema, com o assunto adequado, setor responsável, canal de origem e relato completo, para que a Ouvidoria consiga realizar a tratativa e o acompanhamento necessário.

1. Orientações gerais

Sempre que o cliente trouxer uma situação relacionada a feedback, sugestão ou elogio, o colaborador deverá:

Abrir o registro com o assunto correto, conforme a situação apresentada.

Selecionar o setor da Ouvidoria como responsável pela tratativa.

Manter o atendimento/registro em aberto, para que a Ouvidoria consiga analisar e dar continuidade.

Informar corretamente o canal por onde o cliente trouxe a informação.

Relatar de forma clara e objetiva o que foi informado pelo cliente,se foi pelo whatsapp pode anexar o print do elogio em arquivos do atendimento, caso for áudio por anexar o áudio também.

Quando houver direcionamento para alguma área ou setor específico, preencher corretamente os campos de destino.

2. Canal de atendimento

O canal deve ser preenchido de acordo com o local onde o cliente trouxe a informação.

Exemplos:

WhatsApp: ID 1

Telefonia: ID 2

Caso o cliente tenha trazido a informação por outro canal, selecionar o canal correspondente no sistema.

3. Feedback do cliente

Assunto:

Feedback — ID 620

Quando utilizar:

Esse assunto deve ser utilizado quando o cliente trouxer um feedback sobre alguma situação, atendimento, serviço prestado ou experiência vivida com a empresa.

O feedback pode ser positivo, negativo ou apenas uma observação sobre algo que aconteceu.

Exemplo de situação:

Cliente informou que o técnico foi até o local, realizou o atendimento, porém deixou o ambiente sujo após a execução do serviço.

Como relatar:

O relato deve informar o que aconteceu, quem ou qual setor esteve envolvido, e qual foi a percepção do cliente.

Exemplo de relato:

Cliente entrou em contato informando que o técnico de manutenção esteve no local para realizar o atendimento, porém deixou o ambiente sujo após a execução do serviço. Cliente trouxe esse ponto como feedback sobre a experiência recebida.

4. Sugestão do cliente

Assunto:

CUSTOMER SUCCESS | RECEBIMENTO DE SUGESTÃO — ID 765

Quando utilizar:

Esse assunto deve ser utilizado quando o cliente trouxer uma sugestão de melhoria, ideia ou proposta sobre algum processo, produto, serviço, atendimento ou inovação.

Exemplo de situação:

Cliente sugeriu que a empresa envie os boletos diretamente pelo WhatsApp.

Campos que devem ser preenchidos:

Área:

Marcar a área relacionada à sugestão.

Exemplo:

Área:(X) Inovação

Destinado a qual área?

Selecionar a área que mais se relaciona com a sugestão do cliente.

Opções:

( ) Atendimento( ) Técnico( ) Produto( ) Serviço(X) Inovação( ) Outros

Destinado a qual setor?

Selecionar o setor responsável ou mais relacionado à sugestão.

Opções:

( ) Manutenção( ) Garantia( ) Financeiro( ) Comercial( ) CSC( ) Ouvidoria( ) Projeto( ) Infraestrutura(X) Desenvolvimento( ) Vendas

Como relatar:

O relato deve informar qual foi a sugestão do cliente e, se possível, o motivo pelo qual ele sugeriu essa melhoria.

Exemplo de relato:

Cliente sugeriu que a empresa envie os boletos diretamente pelo WhatsApp, pois acredita que isso facilitaria o acesso ao pagamento e evitaria atrasos por dificuldade em localizar a fatura.

5. Elogio do cliente

Assunto:

CUSTOMER SUCCESS | RECEBIMENTO DE ELOGIOS — ID 942

Quando utilizar:

Esse assunto deve ser utilizado quando o cliente elogiar um atendimento, colaborador, técnico, setor, serviço prestado ou experiência positiva com a empresa.

Exemplo de situação:

Cliente elogiou o atendimento do técnico de manutenção, informando que ele realizou um ótimo atendimento.

Campos que devem ser preenchidos:

Destinado a qual área?

Selecionar a área relacionada ao elogio.

Exemplo:

( ) Atendimento(X) Técnico( ) Produto( ) Serviço( ) Inovação( ) Outros

Destinado a qual setor?

Selecionar o setor ao qual o elogio se refere.

Exemplo:

(X) Manutenção( ) Garantia( ) Financeiro( ) Comercial( ) CSC( ) Ouvidoria( ) Projeto( ) Infraestrutura( ) Desenvolvimento( ) Vendas

Como relatar:

O relato deve informar quem foi elogiado, qual atendimento foi realizado e o que o cliente destacou como positivo.

Exemplo de relato:

Cliente elogiou o atendimento realizado pelo técnico da manutenção, informando que o profissional prestou um ótimo atendimento, foi atencioso e conseguiu auxiliar na resolução da situação.

6. Pontos de atenção

Antes de finalizar a abertura, confira se:

O assunto correto foi selecionado.

O setor da Ouvidoria foi colocado para tratativa.

O registro ficou em aberto.

O canal de atendimento está correto.

O relato está claro e completo.

A área e o setor de destino foram preenchidos corretamente, quando necessário.

O nome do colaborador elogiado foi informado, quando houver elogio direcionado.

A sugestão do cliente foi descrita exatamente como foi apresentada, sem alterar o sentido.

7. Resumo dos assuntos

8. Finalidade do procedimento

Esse procedimento é importante para que a Ouvidoria consiga acompanhar todos os retornos espontâneos dos clientes, sejam eles sugestões, elogios ou feedbacks sobre a experiência.

Com esses registros, conseguimos identificar oportunidades de melhoria, reconhecer bons atendimentos e fortalecer a qualidade da experiência entregue ao cliente.
