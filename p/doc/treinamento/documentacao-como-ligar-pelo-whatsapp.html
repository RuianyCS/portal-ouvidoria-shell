Tutorial — Como realizar ligações pelo WhatsApp

1. Iniciar a ligação

No painel de atendimento do WhatsApp, clique no primeiro ícone de telefone.

2. Solicitar autorização do cliente

Ao clicar no botão e enviar a solicitação, o cliente receberá uma mensagem pedindo autorização para que a empresa realize ligações pelo WhatsApp.

Veja abaixo como a solicitação aparece para o cliente:

3. Confirmar a autorização

Quando o cliente aceitar a solicitação, o indicador de confirmação ficará azul, sinalizando que a autorização foi concedida.

4. Realizar a ligação

Após a autorização, clique novamente no ícone de telefone para iniciar a chamada.

O cliente receberá a ligação normalmente pelo WhatsApp.
